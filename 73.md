NIP-73
======

外部内容 ID
--------------------

`draft` `optional`

有一些既有的全局内容标识符，例如 [Book ISBNs](https://en.wikipedia.org/wiki/ISBN)、[Podcast GUIDs](https://podcastnamespace.org/tag/guid) 和 [Movie ISANs](https://en.wikipedia.org/wiki/International_Standard_Audiovisual_Number)，在 nostr event 中引用它们很有用，这样 client 就可以查询与这些 id 关联的所有 event。


`i` tag 用于引用这些外部内容 id，`k` tag 表示外部内容 id 的 kind，使 client 可以查询特定 kind 的所有 event。

## 支持的 ID

| 类型                   | `i` tag                                                    | `k` tag                  |
| ---                    | ---                                                        | ---                      |
| URLs                   | "`<URL, normalized, no fragment>`"                         | "web"                    |
| Books                  | "isbn:`<id, without hyphens>`"                             | "isbn"                   |
| Geohashes              | "geo:`<geohash, lowercase>`"                               | "geo"                    |
| Countries              | "iso3166:`<code, uppercase>`"                              | "iso3166"                |
| Movies                 | "isan:`<id, without version part>`"                        | "isan"                   |
| Papers                 | "doi:`<id, lowercase>`"                                    | "doi"                    |
| Hashtags               | "#`<topic, lowercase>`"                                    | "#"                      |
| Podcast Feeds          | "podcast:guid:`<guid>`"                                    | "podcast:guid"           |
| Podcast Episodes       | "podcast:item:guid:`<guid>`"                               | "podcast:item:guid"      |
| Podcast Publishers     | "podcast:publisher:guid:`<guid>`"                          | "podcast:publisher:guid" |
| Blockchain Transaction | "`<blockchain>`:[`<chainId>`:]tx:`<txid, hex, lowercase>`" | "`<blockchain>`:tx"      |
| Blockchain Address     | "`<blockchain>`:[`<chainId>`:]address:`<address>`"         | "`<blockchain>`:address" |

---

## 示例


### 网页

对于网页 "https://myblog.example.com/post/2012-03-27/hello-world"，"i" 和 "k" tag 为：

```yaml
[
  ["i", "https://myblog.example.com/post/2012-03-27/hello-world"],
  ["k", "web"]
]
```

### Geohash：

- Geohash: `["i", "geo:ezs42e44yx96"]` - https://www.movable-type.co.uk/scripts/geohash.html

Geohash 是一种地理编码系统，可将地理位置编码为由字母和数字组成的短字符串。它们 MUST 为小写。

### 国家：

ISO 3166 code 可引用国家（ISO 3166-1 alpha-2）或州/省等分区（ISO 3166-2）。

- Country (Venezuela): `["i", "iso3166:VE"]`
- Subdivision (California, USA): `["i", "iso3166:US-CA"]`

ISO 3166 code MUST 为大写。更多信息：https://en.wikipedia.org/wiki/ISO_3166

### 图书：

- Book ISBN: `["i", "isbn:9780765382030"]` - https://isbnsearch.org/isbn/9780765382030

Book ISBN MUST 以_**不带连字符**_的形式引用，因为许多图书搜索 API 返回的 ISBN 不带连字符。从 ISBN 中移除连字符很简单，而重新添加连字符并不简单，需要库支持。

### 播客：

- 播客 RSS Feed GUID：`["i", "podcast:guid:c90e609a-df1e-596a-bd5e-57bcc8aad6cc"]` - https://podcastindex.org/podcast/c90e609a-df1e-596a-bd5e-57bcc8aad6cc
- 播客 RSS Item GUID：`["i", "podcast:item:guid:d98d189b-dc7b-45b1-8720-d4b98690f31f"]`
- 播客 RSS Publisher GUID：`["i", "podcast:publisher:guid:18bcbf10-6701-4ffb-b255-bc057390d738"]`

### 电影：

- Movie ISAN: `["i", "isan:0000-0000-401A-0000-7"]` - https://web.isan.org/public/en/isan/0000-0000-401A-0000-7

Movie ISAN SHOULD 以_**不带版本部分**_的形式引用，因为电影的版本/剪辑无关紧要。关于 ISAN 部分的更多信息见此处：https://support.isan.org/hc/en-us/articles/360002783131-Records-relations-and-hierarchies-in-the-ISAN-Registry

### 区块链

`<blockchain>` 可以是任意 layer 1 chain（`bitcoin`、`ethereum`、`solana` 等）。如有必要（例如 ethereum），可以指定 `<chainId>`。

#### Bitcoin

```
bitcoin:address:<bech32, lowercase | base58, case sensitive>
bitcoin:tx:<txid, hex, lowercase>
```

例如 https://blockstream.info/tx/a1075db55d416d3ca199f55b6084e2115b9345e16c5cf302fc80e9d5fbf5d48d

```yaml
[
  ["i", "bitcoin:tx:a1075db55d416d3ca199f55b6084e2115b9345e16c5cf302fc80e9d5fbf5d48d"],
  ["k", "bitcoin:tx"]
]
```

例如 https://blockstream.info/address/1HQ3Go3ggs8pFnXuHVHRytPCq5fGG8Hbhx

```yaml
[
  ["i", "bitcoin:address:1HQ3Go3ggs8pFnXuHVHRytPCq5fGG8Hbhx"],
  ["k", "bitcoin:address"]
]
```

#### Ethereum（和其他 EVM chains）

```
ethereum:<chainId, integer>:tx:<txHash, hex, lowercase>
ethereum:<chainId, integer>:address:<hex, lowercase>
```

例如 https://etherscan.io/address/0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045

```yaml
[
  ["i", "ethereum:1:address:0xd8da6bf26964af9d7eed9e03e53415d37aa96045"],
  ["k", "ethereum:address"]
]
```

例如 https://gnosisscan.io/tx/0x98f7812be496f97f80e2e98d66358d1fc733cf34176a8356d171ea7fbbe97ccd

```yaml
[
  ["i", "ethereum:100:tx:0x98f7812be496f97f80e2e98d66358d1fc733cf34176a8356d171ea7fbbe97ccd"],
  ["k", "ethereum:tx"]
]
```

### 可选 URL Hints

每个 `i` tag MAY 将 URL hint 作为第二个参数，以便当 client 对如何解释该 id 没有固定意见时，将人们重定向到某个网站：

`["i", "podcast:item:guid:d98d189b-dc7b-45b1-8720-d4b98690f31f", https://fountain.fm/episode/z1y9TMQRuqXl2awyrQxg]`

`["i", "isan:0000-0000-401A-0000-7", https://www.imdb.com/title/tt0120737]`
