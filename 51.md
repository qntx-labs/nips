NIP-51
======

列表
-----

`draft` `optional`

本 NIP 定义了用户可以创建的事物列表。列表可以包含对任何东西的引用，并且这些引用可以是**公开的**或**私有的**。

列表中的公开项目在事件的 `tags` 数组中指定；私有项目则在一个 JSON 数组中指定，该数组模仿事件 `tags` 数组的结构，但会被字符串化并使用与 [NIP-44](44.md) 相同的方案加密（共享密钥使用作者的公钥和私钥计算），然后存储在 `.content` 中。此规范的较早版本使用 [NIP-04](04.md) 进行加密。这些现在已被弃用。为了向后兼容，Client 可以通过在密文中搜索 "iv" 并据此解密，自动发现加密方式是 NIP-04 还是 NIP-44。

当向现有列表添加新项目时，client SHOULD 将它们追加到列表末尾，从而按时间顺序存储。

## 列表类型

<a id="standard-lists"></a>

### 标准列表

标准列表使用普通的可替换事件，这意味着用户对每种 kind 只能有一个列表。它们具有特殊含义，client 可以依赖它们来增强用户的 profile 或浏览体验。

例如，_mute list_ 可以包含用户不希望在 feed 中看到、或不希望收到其烦人通知的 spammer 和恶意行为者的公钥。

### 集合

Sets 是具有明确定义含义的列表，可以增强依赖它们的 client 的功能和 UI。不同于标准列表，用户预计会拥有每种 kind 的多个 set，因此每个 set 都必须分配一个不同的 `"d"` 标识符。

例如，_relay sets_ 可以显示在下拉 UI 中，让用户选择将事件发布到哪些 relay，或从哪些 relay 读取某个事件的回复；_curation sets_ 可由 app 用来展示其他人按不同主题标记的策展内容。

除了主要标识符 `"d"` tag 之外，set 还可以选择带有 `"title"`、`"image"` 和 `"description"` tag，以增强其 UI。

| 名称                  | kind  | 描述                                                                                  | 预期 tag 项目                                                                  |
| ---                   | ---   | ---                                                                                   | ---                                                                            |
| Follow sets           | 30000 | client 在不同场景下可能选择查看的分类用户组                                          | `"p"`（pubkeys）                                                               |
| Relay sets            | 30002 | 用户定义的 relay 组，方便用户在各种操作中挑选                                        | `"relay"`（relay URLs）                                                        |
| Bookmark sets         | 30003 | 用户定义的书签分类，用于书签必须分在带标签的独立组中时                              | `"e"`（kind:1 notes）、`"a"`（kind:30023 articles）                            |
| Curation sets         | 30004 | 用户挑选出的有趣和/或属于同一类别的文章组                                           | `"a"`（kind:30023 articles）、`"e"`（kind:1 notes）                            |
| Curation sets         | 30005 | 用户挑选出的有趣和/或属于同一类别的视频组                                           | `"e"`（kind:21 videos）                                                        |
| Curation sets         | 30006 | 用户挑选出的有趣和/或属于同一类别的图片组                                           | `"e"`（kind:20 pictures）                                                      |
| Kind mute sets        | 30007 | 按 kind mute pubkey<br>`"d"` tag MUST 是 kind 字符串                                 | `"p"`（pubkeys）                                                               |
| Badge sets            | 30008 | [NIP-58](58.md) 分类 badge 组                                                        | `"a"`（kind:30009 badge definitions）和 `"e"`（kind:8 badge awards）           |
| Interest sets         | 30015 | 由一组 "hashtags" 表示的兴趣主题                                                     | `"t"`（hashtags）                                                              |
| Emoji sets            | 30030 | 分类 emoji 组                                                                         | `"emoji"`（见 [NIP-30](30.md)）                                                |
| Release artifact sets | 30063 | 软件发布的 artifact 组                                                               | `"e"`（kind:1063 [file metadata](94.md) events）、`"a"`（software application event） |
| App curation sets     | 30267 | 对多个软件应用的引用                                                                  | `"a"`（software application event）                                            |
| Calendar              | 31924 | 以任意方式分类的一组事件                                                              | `"a"`（calendar event event）                                                  |
| Starter packs         | 39089 | 一个命名 profile 集，用于分享并让这些 profile 被一起关注                            | `"p"`（pubkeys）                                                               |
| Media starter packs   | 39092 | 同上，但专用于多媒体（照片、短视频）client                                           | `"p"`（pubkeys）                                                               |

## 加密流程伪代码

```scala
val private_items = [
  ["p", "07caba282f76441955b695551c3c5c742e5b9202a3784780f8086fdcdc1da3a9"],
  ["a", "a55c15f5e41d5aebd236eca5e0142789c5385703f1a7485aa4b38d94fd18dcc4"],
]
val base64blob = nip44.encrypt(json.encode_to_string(private_items))
event.content = base64blob
```
